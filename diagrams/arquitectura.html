Arquitectura RAG Convencional vs. Agentic RAG

RAG Convencional
Consulta Pregunta del usuario
↓
Recuperador Embeddings + Vector DB + Top-k
↓
Recuperación única
Documentos / Chunks relevantes
↓
Generador LLM + contexto recuperado
↓
Respuesta estructurada Hechos + indicadores + citas

Características

  • Flujo estático
  • Una recuperación principal
  • Sin planificación dinámica
  • Menor número de llamadas al modelo
  • Línea base experimental
Agentic RAG
Consulta Pregunta del usuario
↓
Coordinador Planificación y decisión de ruta
Decisión dinámica
Recuperar → Analizar → Reintentar → Finalizar
↓
Agente de Evidencia Buscar / reformular / recuperar
↓
Agente Analista Extraer hechos + indicadores + citas
↓
Validador determinista Esquema + citas + correspondencia con evidencia
❌ Evidencia insuficiente o validación fallida
→ Reintento limitado
↓
Respuesta estructurada Hechos + indicadores + incertidumbre + citas

Características

  • Decisiones dinámicas durante la ejecución
  • Recuperación adaptativa
  • Especialización funcional
  • Estado compartido y trazabilidad
  • Reintentos con límite de pasos
