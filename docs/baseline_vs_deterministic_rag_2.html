RAG Pipeline Architectural Comparison

Desviaciones Estructurales: Classic Linear RAG vs. Multi-Agent Validation Loop

🟦 Classic Baseline RAG (Linear)
Fase 01
📂 Recuperación Indexada
Extracción vectorial local directa sobre índice FAISS (k=5 Chunks) sin filtrado previo.
↓
Fase 02
📦 Ensamble de Contexto
Concatenación estática de fragmentos crudos dentro del prompt del LLM de manera pasiva.
↓
Fase 03
🤖 Inferencia LLM Directa
Ejecución directa del modelo gpt-4o-mini sin análisis ni filtros de veracidad intermedios.
↓
Fase 04
💬 Respuesta Plana Obtenida
Salida directa al usuario final. Al carecer de capas de control estructural, es altamente vulnerable a alucinaciones.
🟧 Deterministic Agentic RAG (Loop)
Fase 01
🔍 Recuperación Inicial
Idéntico paso de extracción de contexto k=5 mediante FAISS Index para garantizar condiciones base homogéneas.
↓
Cambio Estructural Fase 02
🧠 Intervención: AnalystAgent
Un agente especializado asume el control del prompt para procesar, segmentar y consolidar la información estructuradamente.
↓
Bucle de Validación Fase 03
⚖️ Ciclo: EvidenceAgent + AnswerValidator
Extracción rigurosa de fuentes seguida por un proceso iterativo de contrastación. Si se detectan inconsistencias, el flujo se repite deterministamente mediante el estado hasta cumplir max_steps.
↓
Garantía Estructural Fase 04
🎯 Respuesta Certificada con Citaciones
Salida final blindada algorítmicamente contra la alucinación. El diseño del grafo mitiga la desviación factual asegurando el rastro de citación exacta.
