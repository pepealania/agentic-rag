📌 Architecture Routing Behavior:
All worker nodes in the Execution Column naturally route state transactions back to the adaptive_router on completion. However, if the coordinator triggers a true exception recovery state, the retry_* sub-nodes override the router path and cycle straight back into their designated parent worker task.
