IDEA CLAVE DEL BASELINE
Indexación offline: documentos → chunks → embeddings → índice FAISS.
Ejecución online: pregunta → embedding de query → FAISS Search → chunks recuperados → prompt → LLM → validación.
La única vectorización que ocurre por cada pregunta es la del embedding de la query.
